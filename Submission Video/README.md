## Git and large media

This folder includes a local `.gitignore` for video, audio, caches, and editor bundles. Keep scripts, small graphics, instructions, and source/license records in Git. Store heavy recordings and exports in a team-shared folder and link them from `05-asset-register.md`. This keeps the production folder as the index for all video work without adding large binaries to every teammate's clone. If the team deliberately adopts Git LFS later, update this policy together.

Git tracks files rather than empty folders; `.gitkeep` files preserve the starter structure.

## Start here

1. Verify submission rules: maximum duration, required content, aspect ratio, upload destination and file size.
2. Get agreement on one demonstrable nonprofit workflow and a capture-ready deadline.
3. Export a ten-second test from your selected tools before building the entire edit.
4. Record narration and build a 90-second timeline with clearly named footage placeholders.
5. Replace placeholders with real captures, confirm claims, and export with time reserved for upload.
