# Production plan

## Recommended tools

**Screen Studio → CapCut Desktop → H.264 MP4.**

Screen Studio records the website and handles smooth cursor movement, click indicators, automatic/manual zoom, framing and motion blur. CapCut assembles the story, titles, narration, music and precisely timed effects. Your previous After Effects and Sony Vegas experience should transfer to timeline editing and keyframes.

Screen Studio's official site lists $29/month, or $9/month billed yearly, and a 40% student/educator discount as checked October 11, 2026. For this deadline, the monthly plan avoids the annual commitment. Check the checkout price and renewal terms yourself. No software has been purchased or installed as part of this kit.

Use CapCut's basic editing features first; test your chosen assets/effects and final export before committing to them because some items require Pro. If you already have a familiar licensed editor installed, it can replace CapCut. Use After Effects only for a small title animation if it is already available and comfortable; do not spend the production window building an elaborate new motion system.

Zero-cost capture fallback: macOS Screenshot recording (Shift–Command–5), then manually animate scale/position and a click ring in the editor. This requires more motion work.

## Direction

Make a focused product launch film with one human problem and one concrete demonstration. A nonprofit's outgoing operations coordinator knows how the weekly volunteer shift is organized. OrgFlow helps preserve that process so the next coordinator can act.

Design the opening around disappearing knowledge: a few document/email cards drift apart; a single question remains, “Who knows how this works?” On the brand reveal, the cards align into one clean playbook. These are conceptual graphics, not fabricated product UI.

Use the actual site's typography and accent color once available. Until then, use neutral backgrounds, one accent, large type, generous space and a consistent browser frame. Match the final site before export.

Reserve the biggest motion for three moments: brand reveal, playbook reveal, final handoff. During reading, hold the screen still. Avoid zooming on every click.

## Six-hour schedule (elapsed from your production start)

| Time | Deliverable |
| --- | --- |
| 0:00–0:25 | Confirm submission rules, product name, demo path and capture deadline; test tools and export |
| 0:25–1:00 | Lock narration, record two takes, choose music and three effects |
| 1:00–1:50 | Build opening, end card and complete 90-second placeholder timeline |
| 1:50–2:30 | Rehearse one zoom/click sequence; prepare titles and source/asset register |
| 2:30–3:20 | Capture working website in short independent takes; obtain result stills |
| 3:20–4:20 | Replace placeholders, trim actions, set zooms, make first full cut |
| 4:20–5:00 | Sound design, readable captions, brand consistency and teammate fact check |
| 5:00–5:30 | Export, watch the entire exported file, correct only material issues |
| 5:30–6:00 | Upload, verify playback/access and retain a backup |

The team's critical dependency is a stable demo path by about hour 2.5, with final usable footage by hour 3.5. Ask for this early. You can prepare the rest before the site is finished.

If the build slips, use the strongest working flow as the centerpiece. Shorten the feature list. Clearly label any future-feature graphic “Planned”; never cut a mockup into the film as evidence that it works. If rules require a functioning demo, retain visible working product proof.

## Priority order under pressure

1. Clear problem, readable working demo, accurate claims, understandable voice.
2. Consistent framing, three intentional zooms, concise titles.
3. Music and restrained click/transition sounds.
4. Extra decorative animation only if the exported cut is already safe.
